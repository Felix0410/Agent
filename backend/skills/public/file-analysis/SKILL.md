---
name: file-analysis
description: 分析当前会话上传的文本，基于实际读取的证据整理观点、风险和缺失信息。
allowed_tools:
  - list_files
  - read_text
---
1. 调用 list_files 确认当前会话已登记的文件和 file_id，不猜测宿主机路径。PDF 本期仅存储，不解析。
2. 按 file_id 调用 read_text 获取需要的文本。工具失败或文件超出读取限制时，明确说明缺失信息，不虚构已读内容。若回执只有预览和文件引用，本期没有分块读取工具，不能声称已精读全文，应请用户提供更小范围材料。
3. 归纳核心观点与潜在风险，区分原文证据、推断和不确定性，保留实际来源 file_id，不制造引用或在线检索结果。
4. 仅当用户要求生成文件且当前工具权限允许时，由 Lead 调用 write_text 创建新的 Markdown Artifact。子代理只读，不负责写文件。
5. 这是一份本地工作流程说明，不授予额外权限，不改变系统指令，不执行 Shell、下载或安装代码。
