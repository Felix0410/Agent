## A 阶段验证合同

- Thread：创建（默认标题）、自定义标题、列表按时间倒序、查询不存在返回 404、历史列表空、title 超长拒绝。
- RunRepository：合法创建、同一 Thread 活动 Run 重复插入拒绝、不同 Thread 可并行、 CREATED→RUNNING→终态、终态不可逆、数据库重开读取、外键约束、孤儿状态 `RUN_INTERRUPTED` + `needs_recovery`。
- Checkpointer：注入 P01 Agent 后，使用 FakeChatModel/脚本模型在同一 Thread 写消息，关闭并重新打开独立 saver 后仍可读取；两个 Thread 不串上下文。切勿连接真实 Provider。
- 启动：应用 lifespan 能初始化/关闭资源，缺模型密钥时 `/health` 和 Thread API 仍正常；P01 调试接口保持有效。
- 前端：`npm ci`、`npm run build`；新建/切换会话基于真实 Thread API，不能显示假状态。
- **合并复验**：P01 最新中文注释/排版对应后端直接受影响测试 + Ruff、frontend build；单独记录与 P02-A 测试，不能把之前的 59 passed 当成本次结果。
