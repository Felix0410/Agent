## 关键设计结论

- 仅本地单 Worker；`aiosqlite` 业务库与 `AsyncSqliteSaver` Checkpoint 分库。
- Run 状态 `CREATED → RUNNING → SUCCEEDED/FAILED`，终态不可逆；单 Thread 唯一活动 Run；最多 2 个执行中、8 个排队。
- SSE 事件来源必须是真实 LangGraph 消息，单 Run 512 条事件缓存、每订阅者 64 条通知上限、终态保留 10 分钟；断线不取消任务、缺口明确告知并查 Run。
- 新增历史 Run 查询，确保网页刷新恢复；会话记忆来自 Checkpoint，不从 Run 文本拼凑。
- 启动保守处理遗留运行中 Run，标记 `FAILED/RUN_INTERRUPTED` 并使相关 Thread 进入需恢复状态；不承诺 P02 无损续跑。
- P01 原路由、CLI、健康检查、计算器和 React 调试区保留；每个 P02 子任务同期更新可见的前端能力。
- 新改文件遵守根目录 `AGENTS.md`：中文解释核心机制，复杂步骤 `1./2./3.` 分段；不为中文注释改动模型可见工具 Schema。
