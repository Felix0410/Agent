## 本阶段业务目标

真实的 Thread 文件链路：上传文本或 PDF → Workspace 安全存储与元数据 → Agent 通过可信 ToolRuntime 读取文本和创建新文件 → Artifact 登记/列表/下载 → 前端刷新/重启后仍可访问。文件工具不允许模型提供 Thread ID、Run ID 或宿主机路径。

范围/安全约束/逐文件细节/API/局部测试以 P03 设计合同和 Codex 实施清单为准，本文件只记录已发生的事实。
