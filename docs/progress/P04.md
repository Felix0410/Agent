## 业务目标

在现有 P03 Thread Run 上，模型按需使用 `write_todos` 写真实 Todo/Checkpoint/SQL 快照，以 `task` 委派受限的 `general/research` 子 Agent；子代理不继承父完整历史/Checkpoint、不重复委派、不越权写文件。数据库记录每个 Run 的 Todo/Subtask，SSE 推送真实状态，React 显示历史和实时进度。父 Agent 汇总后可沿用 P03 的 `write_text` 生成下载产物。
